# Rosan (Rosannalie)

A modern Flutter application.

## Overview

This project is a Flutter application that leverages several powerful packages to deliver a rich user experience:
- **State Management & Routing:** [GetX](https://pub.dev/packages/get)
- **Typography:** [Google Fonts](https://pub.dev/packages/google_fonts)
- **Networking:** [http](https://pub.dev/packages/http)
- **Local Storage:** [shared_preferences](https://pub.dev/packages/shared_preferences)
- **Media & Assets:** [flutter_svg](https://pub.dev/packages/flutter_svg), [video_player](https://pub.dev/packages/video_player), and [image_picker](https://pub.dev/packages/image_picker)
- **Testing/Preview:** [Device Preview](https://pub.dev/packages/device_preview)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Flutter SDK (version 3.12.1 or higher)
- Dart SDK

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

## Project Structure

- `lib/` - Contains the main Dart code for the application.
  - `core/` - Core services, API configurations, and controllers.
  - `presentation/` - UI components, screens, and widgets.
- `assets/` - Contains images, icons, and other static files.
